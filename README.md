# startup-research

Ветка про **критерий развёртывания предсказательных систем**: когда предсказательная система добавляет ценность решению, а когда отнимает.

Не про предсказание успеха стартапов. Про пределы предсказания и про то, что в венчуре эти пределы эндогенны самому предиктору.
