## 0. Что демонстрируется и что демонстрацией НЕ является

Проверяется **одно**: поднимается ли оценённая снизу доля объекта `B` на публичных данных настолько, что граница на достижимый выигрыш опускается ниже порога существенности — то есть непуста ли область, объявленная в `00-context/00-THESIS.md`.

Это **не** утверждение о предсказуемости выбранной предметной области, **не** сравнение моделей и **не** результат о стартапах. Данные берутся как стенд для проверки невырожденности конструкции, и так и будут описаны.

## 1. Вычисляемая величина

Пусть `S` — объявленный до расчёта конечный набор категориальных признаков, `Y ∈ {0,1}` — исход, `η(x) = P(Y=1 | X=x)`, `π = E[Y]`.

Целевая величина — **неустранимый брайеровский риск при объявленном наборе**:

```
ε* := E[ η(1−η) ]          B := ε* / ( π(1−π) )          σ² := Var(η) = π(1−π)(1−B)
```

Ячейка `c` — различный кортеж значений `S`. Обозначения: `n` — объём выборки, `n_c` — число наблюдений в ячейке, `k_c` — число положительных, `η̂_c = k_c/n_c`, `π̂ = (Σ k_c)/n`.

### 1.1 Несущий оценщик — внутривыборочный plug-in (C3, C4)

```
ε̂_pi = Σ_c (n_c/n) · η̂_c (1 − η̂_c)            B̂_pi = ε̂_pi / ( π̂(1−π̂) )
```

Ячейки с `n_c = 1` дают ровно нулевой вклад — это конструкция, а не упущение (C4). `E[ε̂_pi] ≤ ε*`, поэтому `B̂_pi` — оценка **снизу**, то есть требуемая сторона (G8).

### 1.2 Вторая сторона зажима — `CV_TL`

Пятикратная стратифицированная кросс-валидация, **seed 20260820 объявляется здесь**. На фолде `f` таблица строится по дополнению: `η̃_c^(−f) = k_c^(−f) / n_c^(−f)`; для ячеек, не встреченных в обучающих фолдах, предсказание — базовая ставка обучающих фолдов `π̂^(−f)`. Вневыборочный брайер:

```
ε̂_cv = (1/n) · Σ_i ( y_i − η̃_{c(i)}^(−f(i)) )²        B̂_cv = ε̂_cv / ( π̂(1−π̂) )
```

Вневыборочный риск любого реального правила не меньше байесовского, поэтому `E[ε̂_cv] ≥ ε*`.

### 1.3 Зажим

```
E[ε̂_pi] ≤ ε* ≤ E[ε̂_cv]           зажим на B:  [ B̂_pi , B̂_cv ]
```

Вердикт строится **только** на `B̂_pi`. `B̂_cv` служит измерителем ширины и ничем больше (C3).

### 1.4 Односторонний нижний предел (C5)

Непараметрический бутстрап по строкам, `1000` пересэмплирований, **seed 20260821 объявляется здесь**. `B_L` := 5-й процентиль бутстрапного распределения `B̂_pi`, то есть односторонний 95-процентный нижний предел. Вердикт строится на `B_L`, а не на точке.

Пересэмплирование само разрежает ячейки и потому смещает `B̂_pi` ещё ниже. Это консервативно, то есть в требуемую сторону; отмечается здесь заранее, чтобы потом не быть предъявленным как открытие.

## 2. Граница и условие переворота — записаны до данных

Используется **острая форма Скарфа** `[REF: Scarf 1958]`, а не наша грубая (`01-literature/06-BOUND-PRIOR-ART-2026-08-20.md`):

```
U(p_t ; σ)  :=  [ √( σ² + (π̂ − p_t)² ) − |π̂ − p_t| ]  /  ( 2 (1 − p_t) )
```

`U` ограничивает сверху `NB* − NB_безмодели` — достижимый выигрыш net benefit над решением без модели.

**Две версии, различающиеся ровно тем, оценена доля объекта или нет:**

```
U_ours (p_t)  =  U( p_t ; √( π̂(1−π̂)(1 − B_L) ) )      потолок оценён снизу
U_naive(p_t)  =  U( p_t ; √( π̂(1−π̂) ) )               потолок не оценён, B положен в 0
```

`U_naive` — это в точности то, что остаётся при нормировке на совершенный прогноз: у `[REF: Baker, Cook, Vickers & Kramer 2009]` потолок предполагается достижимым, то есть `B` логически положен в минимум.

**Сетка порогов объявляется здесь:** `p_t ∈ {0.02, 0.05, 0.10, 0.20, 0.30, 0.50}`. Иные значения не сообщаются.

**Диапазон существенности объявляется здесь:** `δ ∈ [0.001, 0.05]` в единицах net benefit (чистых истинно-положительных на наблюдение) — от одного лишнего попадания на тысячу до пяти на сотню.

**Условие переворота вердикта при пороге `p_t`:**

```
U_ours(p_t)  ≤  δ  <  U_naive(p_t)
```

## 3. Что считается непустой областью — три клаузы, все обязательны

Читаются **на уровне чтения** (раздел 4), и только на нём.

- **R1 — существенность.** `U_naive(p_t) / U_ours(p_t) ≥ 2` хотя бы при одном объявленном `p_t`. То есть оценка потолка должна ужимать границу минимум вдвое; иначе переворот формально есть, но ничего не значит.
- **R2 — защитимость.** Интервал переворота `[ U_ours(p_t) , U_naive(p_t) )` пересекается с объявленным диапазоном `δ ∈ [0.001, 0.05]` при том же `p_t`.
- **R3 — режим.** `B_L ≥ 0.5` **и** `π̂ ≤ 0.15`. Демонстрируется режим редкого исхода при существенной неустранимой доле; при `π̂ > 0.15` демонстрируется не тот режим, и результат не засчитывается, каким бы он ни был.

**Область непуста ⟺ R1 ∧ R2 ∧ R3.** Ни одна клауза не заменяется другой.

## 4. Уровни огрубления и уровень чтения — объявляются здесь структурно

Набор `S` объявляется в `01-RESULT.md` в момент выбора данных, **до расчёта**, вместе с кардинальностью каждого признака и числом ячеек `K` (артефакт G1). После этого сетка уровней определена однозначно и выбора не остаётся:

Признаки упорядочиваются по кардинальности **по убыванию**; равные кардинальности разрешаются по имени признака в алфавитном порядке. Тогда

- `L0` — все `p` признаков,
- `L1` — снят признак с наибольшей кардинальностью,
- `L2` — сняты два наибольших,
- …
- `L_{p−1}` — остался один признак с наименьшей кардинальностью,
- `L_p` — признаков нет, одна ячейка; здесь `B ≡ 1` по построению, и уровень служит проверкой корректности кода, а не результатом.

**Сообщаются все уровни.** Выбор подмножества уровней после расчёта запрещён.

**Диагностика населённости на каждом уровне (G2, C6):**

```
occ  := доля выборочной массы в ячейках с n_c ≥ 2
I_P  := Σ_c (n_c/n) · | 2η̂_c − 1 |      (наша операционализация перфекционного индекса; только диагностика)
```

**Уровень чтения := самый мелкий (наименьший индекс) уровень `L_j`, на котором `occ ≥ 0.90`.**

Если такого уровня нет ни одного — **исход D**, немедленно, без чтения оценок.

## 5. Что считается провалом — исход D и его отличение от малой доли объекта

Пороги объявляются здесь, до данных, как того требует протокол.

- **D-a. Населённость.** Ни на одном уровне `occ < 0.90` → **исход D**.
- **D-b. Ширина зажима.** На уровне чтения `B̂_cv − B̂_pi > 0.25` → **исход D**. Данные не определяют величину; это несущий признак, потому что использует обе стороны и не требует внешнего эталона.
- **D-c. Вырождение границы.** На уровне чтения `B_L < 0.5` при **узком** зажиме (`≤ 0.25`) → это **не** D, а **исход A на этом наборе**: доля объекта действительно мала. Область при этом всё равно пуста (нарушена R3).

Различение D-b и D-c — то самое, ради которого исход D заводился отдельно: одинаковая наблюдаемая картина, противоположный смысл.

**Диагностика `I_P` сообщается на всех уровнях, но вердикта не несёт.** Порог не объявляется намеренно: несущий признак — ширина зажима, и подстраховывать его вторым порогом значило бы дать себе две попытки.

**Любой из исходов D, A или «R1–R3 не выполнены» означает одно и то же действие: ветка закрывается, не пишется ничего.** Ни заметки, ни комментария, ни «отрицательного результата как результата» в форме публикации. Записывается вердикт в волт и всё.
