# DATA ACCESS — что реально доступно

> Проверено 2026-08-18. Уровень: `[SEARCH-SNIPPET]` если не помечено иначе. Перед началом сбора — открыть каждый источник лично и убедиться в наличии нужных полей.

---

## Ограничение проекта

Институционального доступа нет. Бюджета нет. Всё, что не бесплатно и не публично, из дизайна исключается — не как компромисс, а как условие задачи.

---

## Закрыто

| Источник | Статус |
|---|---|
| Crunchbase API | Бесплатный тир фактически закрыт; платный от ~$49/мес |
| PitchBook | Порядок $20–70k/год по отзывам покупателей |
| VCExperts (COI) | Платный. Это источник Gornall & Strebulaev для уставов |
| OpenCorporates API / bulk | Платный; бесплатен веб-поиск и доступ по заявке для академиков/НКО/журналистов |

**Следствие для дизайна.** Любая ветка, где нужно конкурировать по метрике с работами на PitchBook, отпадает автоматически. Это одна из причин, почему тезис построен вокруг потолка и критерия развёртывания, а не вокруг точности.

## Открыто

| Источник | Что даёт | Замечание |
|---|---|---|
| SEC EDGAR — Form D Data Sets | Структурированные данные уведомлений об освобождённых размещениях (Rule 504, 506(b), 506(c)); обновление ежеквартально | Близко к переписи по раундам в США. Нет оценки компании и нет структуры раунда |
| SEC EDGAR — S-1 | Структура капитала до размещения, описание классов акций; устав обычно в приложениях | **НЕ ПРОВЕРЕНО ЛИЧНО.** Проверить состав exhibit 3 на 2–3 недавних IPO |
| Публичный снапшот Crunchbase 2013 | Используется как открытый бенчмарк в свежих работах | Старый; покрытие смещено |
| UK Companies House | Free Company Data Product (месячный bulk) + REST API по ключу | Бесплатно |
| data.egov.kz — ГБД ЮЛ | Регистрационные данные юрлиц КЗ | Нет ИП. Ветка R1 отклонена, источник оставлен на случай возврата |
| Jay Ritter IPO data | Год основания, характеристики фирмы при IPO | site.warrington.ufl.edu/ritter |

## Что ещё не решено про данные

Выбор источника зависит от D1 (единица наблюдения) и D2 (определение исхода). Пока они открыты, сбор не начинается — иначе соберём не то.

Открытый вопрос без ответа: существует ли публичный источник вариации, позволяющий идентифицировать коэффициент перформативности (D4). Если нет — блок 3 теоретический.
