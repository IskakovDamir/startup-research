# ВЕРДИКТ

**КОНСТРУИРУЕМА.** Консервативная односторонняя граница существует, и её направление верно **по построению**, а не по счастливому совпадению знаков.

Но конструкция не та, которую предписывал гейт до переоткрытия, и это главное содержание файла: **гейт предписывал оценщик с неверным направлением.** Кросс-валидированный Table Lookup, записанный в `01-IDENTIFIABILITY-GATE.md` как «оценщик при пройденных G1–G3», ограничивает неустранимую ошибку **сверху**. Вердикту «не разворачивать» нужна граница **снизу**. Нужный оценщик — тот, который литература называет наивным: внутривыборочный plug-in, он же ILD.

Цена конструкции названа честно в разделе 3: направление верно всегда, **острота падает до нуля** по мере разрежения ячеек. То есть критерий никогда не выдаёт неверный вердикт — он перестаёт выдавать вердикт вообще. Это ровно то поведение, которого требует G8, и ровно то, которое делает G8 выполнимым.

# 1. КАКУЮ СТОРОНУ ТРЕБУЕТ ВЕРДИКТ (задача 2)

Выведено из решающей задачи, а не принято на веру.

## 1.1 Обозначения

Исход `Y ∈ {0,1}`, базовая ставка `π = P(Y=1)`. Объявленный набор признаков `X`; условный риск `η(X) = P(Y=1 | X)`. Порог решения `p_t`, пороговые шансы `w = p_t/(1−p_t)`.

Доля объекта в квадратичной (брайеровской) метрике:

```
π(1−π) = Var(η) + E[η(1−η)]          (закон полной дисперсии)
B := E[η(1−η)] / (π(1−π))            доля объекта
⇒ Var(η) = π(1−π)(1−B) =: σ²
```

`B = 1` — признаки не двигают риск вовсе; `B = 0` — риск детерминирован признаками.

## 1.2 Net benefit сводится к одной величине `[ВЫВОД]`

Определение из линии decision curve analysis, дословно:

> «net benefit = sensitivity × prevalence – (1 – specificity) × (1 – prevalence) × w where w is the odds at the threshold probability» `[FETCH: https://www.ebi.ac.uk/europepmc/webservices/rest/PMC6777022/fullTextXML · 2026-08-19]`

и смысл порога у первоисточника:

> «the threshold probability at which a patient will opt for treatment is informative of how a patient weighs the relative harms of false-positive and false-negative results» `[FETCH: https://pmc.ncbi.nlm.nih.gov/articles/PMC2577036/ · 2026-08-19]`

Подставляя `w = p_t/(1−p_t)` и правило «лечить при `η ≥ p_t`», получаем для **наилучшей достижимой** внутри объявленного набора признаков системы:

```
NB* = E[ 1{η ≥ p_t}·(η − w(1−η)) ] = E[(η − p_t)₊] / (1 − p_t)
```

Стратегии без модели: treat-none даёт 0, treat-all даёт `(π − p_t)/(1−p_t)`. Значит

```
NB* − NB_безмодели = G(p_t) / (1 − p_t),     где   G(a) := E[(η − a)₊] − (π − a)₊  ≥ 0
```

Неотрицательность — по выпуклости `(·)₊` (Йенсен). **`G` равно нулю тогда и только тогда, когда `η` почти наверное не пересекает порог.**

## 1.3 Cost-loss сводится к той же величине `[ВЫВОД]`

Постановка, дословно: действие стоит `C`, бездействие при наступлении события даёт потерю `L`,

> «if the decision-maker tries to minimise their expected expense, and they believe that a severe season will occur with probability p, then they should act whenever the expense of acting (C) is less than the expected expense of not acting (pL). In other words if C < pL, or equivalently p > C/L» `[FETCH: https://arxiv.org/pdf/2601.05921v1 · 2026-08-19]`

и нормировка ценности:

> «VS = (Eb − Ef)/(Eb − Ep)», где «Ep is the expected expense when relying on a perfect or oracle forecast» `[FETCH: https://arxiv.org/pdf/2601.05921v1 · 2026-08-19]`

Обозначим `a = C/L` — порог. Тогда `E_b = L·min(a,π)`, `E_оракул = L·aπ`, а наилучшая достижимая `E* = L·(π − E[(η−a)₊])`. Отсюда

```
VS* = G(a) / [ min(a,π) − aπ ]
```

**Два критерия — одна и та же величина `G`.** Decision curve analysis и cost-loss различаются только нормировкой знаменателя. Это надо занести отдельно: спор о том, какой из двух критериев брать, для вопроса о направлении беспредметен.

## 1.4 Связь `G` с долей объекта `[ВЫВОД]`

Одна элементарная оценка, равномерная по порогу:

```
Для любого a:      G(a) ≤ σ/2 = ½·√( π(1−π)(1−B) )
```

Доказательство в две строки. При `a ≥ π`: `(η−a)₊ ≤ (η−π)₊` поточечно и `(π−a)₊ = 0`, значит `G(a) ≤ E[(η−π)₊] = ½·E|η−π| ≤ ½·σ` (последнее — Коши–Буняковский). При `a < π`: `E[(η−a)₊] = (π−a) + E[(a−η)₊]`, значит `G(a) = E[(a−η)₊] ≤ E[(π−η)₊] = ½·E|η−π| ≤ ½·σ`. ∎

Итог:

```
NB* − NB_безмодели ≤ √( π(1−π)(1−B) ) / ( 2(1−p_t) )
VS*                ≤ √( π(1−π)(1−B) ) / ( 2·[min(a,π) − aπ] )
```

Обе правые части **убывают по B**. Граница остра там, где живёт вердикт: при `B → 1` она стремится к нулю вместе с истинным значением. При высокой предсказуемости она груба — но там вердикт «не разворачивать» и не выносится.

## 1.5 Направление: ПОДТВЕРЖДЕНО, с одной поправкой к формулировке

Подставим вместо `B` любую величину `B_низ ≤ B`. Тогда `1 − B_низ ≥ 1 − B`, правая часть **увеличивается**, и неравенство остаётся верным. Значит:

> **Занижающая оценку доли объекта граница даёт корректный вердикт.** Если даже при `B_низ` достижимый выигрыш над решением без модели не превышает порога существенности `δ`, то при истинном `B` он тем более не превышает. Завышающая граница вердикта не поддерживает вовсе: из `B_верх ≥ B` не следует ничего о правой части.

**Чтение PI подтверждено.** Нужна граница **снизу** на долю объекта.

**Поправка, которую надо внести.** Формулировка «вердикт опирается на то, что доля объекта велика» неточна и в таком виде в текст пойти не может. Большого `B` самого по себе не достаточно и не необходимо: в неравенство `B` входит **только через `σ² = π(1−π)(1−B)`, то есть совместно с базовой ставкой**, и сравнивается с порогом существенности, а не с абстрактной «большой величиной». Вердикт несёт тройка `(B, π, δ)` при данном `p_t`, а не `B`. Практическое следствие: при очень редком исходе `π(1−π)` мало само по себе, и вердикт «не разворачивать» может проходить при **умеренном** `B`. Это и есть та «область параметров, в которой вердикт переворачивается», которая в `00-THESIS.md` до сих пор стояла как обещание без выражения.

## 1.6 Два известных смещения по сторонам границы

- **Разрежение ячеек** (кажущаяся детерминированность). Занижает `B`. По разделу 1.5 — **безопасная сторона**. Ошибка возможна только в сторону «не смогли вынести вердикт», никогда — «вынесли неверный».
- **Огрубление.** Здесь поправка существеннее, чем ожидалось. Под **объявленным заранее** набором признаков огрубление — вообще не смещение: оно определяет оцениваемую величину. Смещением оно становится в двух других местах: (i) если вердикт читают как утверждение о более богатом наборе — тогда это **ограничение области**, а не член оценки, и Corollary 5 запрещает перенос вверх; (ii) если степень огрубления выбрана **после** просмотра данных — тогда это настоящее враждебное смещение отбора, и лечится оно объявлением набора до расчёта, то есть условием G1, а не поправкой к оценщику.

То есть двух сонаправленно спорящих смещений внутри одной оценки **нет**. Есть одно смещение внутри оценки (разрежение, безопасное) и один квантор снаружи (огрубление). Это снимает вопрос о «нетто-направлении» в том виде, в каком он был поставлен.

# 2. НАПРАВЛЕНИЕ И ВЕЛИЧИНА СМЕЩЕНИЯ РАЗРЕЖЕНИЯ (задача 3a)

## 2.1 Общая теорема, покрывающая все оценщики этого семейства `[ВЫВОД]`

Неустранимая ошибка в ячейке — это `r*(P) = inf_f E_P[ℓ(f, Y)]`, инфимум по решающим правилам. При фиксированном правиле выражение **линейно** по `P`. Инфимум семейства линейных функций **вогнут**. Эмпирическое распределение несмещено: `E[P̂] = P`. Значит по Йенсену для вогнутых функций

```
E[ r*(P̂) ] ≤ r*(P)
```

**Plug-in занижает неустранимую ошибку при любой функции потерь.** Не при квадратичной, не при 0-1 — при любой. Это одна строка, и она закрывает вопрос о направлении для всего семейства: квадратичная потеря, 0-1 потеря (ILD), логарифмическая потеря (условная энтропия). Разрежение — не особый случай, а предельный: чем меньше наблюдений в ячейке, тем больше зазор Йенсена.

## 2.2 Величина: два разных порядка, и это влияет на выбор оценщика `[ВЫВОД]`

**Квадратичная потеря — смещение известно точно.** В ячейке с `m` наблюдениями и `η̂` — долей единиц: `E[η̂(1−η̂)] = η(1−η)·(1 − 1/m)`. Смещение ровно множителем `(1 − 1/m)`, поправка `m/(m−1)` снимает его полностью при `m ≥ 2`. При `m = 1` вклад ячейки тождественно нулевой — то есть максимально консервативный.

**0-1 потеря — ИСПРАВЛЕНО 2026-08-19, прежнее утверждение было слишком сильным.**

Прежняя редакция: «смещение порядка `m^(−1/2)` против `m^(−1)` у квадратичной», и на этом основывался выбор брайеровской метрики. Проверено прямым перечислением по биномиальному распределению (не симуляцией). Результат:

- Ровно в изломе, `η = 1/2`: показатель сходится к `0.500` при росте `m` — `m^(−1/2)` **подтверждено**.
- В стороне от излома (`η = 0.35`, `0.2`): смещение падает **сверхполиномиально**, при умеренных `m` уходит в машинный ноль. То есть `m^(−1/2)` — не типичный режим, а режим, локализованный у `η = 1/2` в полосе ширины порядка `m^(−1/2)`.
- **Агрегат по ячейкам решает дело.** При разбросанном по ячейкам `η` (равномерная сетка) показатель агрегированного смещения 0-1 равен `0.99–1.00` — тот же порядок `m^(−1)`, что и у квадратичной. Разница рейтов **исчезает**. Она сохраняется (показатель `0.50`) только если ненулевая доля выборочной массы сидит **точно** в изломе, причём величина этой доли влияет на множитель, но не на показатель.

**Следствие: прежний довод в пользу брайеровской метрики не выдержал проверки и снят.** Разница в скорости исчезновения смещения не является общим свойством — она требует атома массы ровно в `η = 1/2`.

**Чем выбор брайеровской метрики обоснован на самом деле** (эти основания от проверки не зависят и сильнее снятого):

1. **Совместимость с алгеброй решения.** Неравенство раздела 1.4 идёт через `Var(η) = π(1−π)(1−B)` — это ровно брайеровское разложение. Байесовская ошибка классификации в это неравенство не входит.
2. **Порог.** Байесовская ошибка при 0-1 потере отвечает порогу `1/2`. Наш порог `p_t` — отношение цен ошибок, и он вообще не обязан быть близок к `1/2`. При редком исходе правило, оптимальное по точности, есть «никогда не действовать», а байесовская ошибка вырождается в `π` и о решении при `p_t` не сообщает ничего. Это возражение решающее и не зависит ни от каких скоростей.
3. **Точность известна в замкнутой форме.** Смещение квадратичного маршрута равно `η(1−η)/m` на ячейку — точно, без асимптотики, поверяемо поячеечно. У 0-1 маршрута замкнутой формы нет, и величина смещения зависит от того, где `η` стоит относительно излома.

**Провенанс этой правки.** Литература вопрос **не решила**. Релевантная линия существует — оценивание негладких функционалов (`Cai & Low 2011`, Annals of Statistics) и оценивание функционалов дискретных распределений методом максимального правдоподобия (IEEE TIT 2015, 2017) — но подтверждены **только метаданные через OpenAlex**, полные тексты не открывались, и в выводе на них ничего не опирается `[метаданные, не читано]`. Исправление получено собственным точным перечислением. В волте это должно читаться именно так, а не как установленный литературой факт.

## 2.3 Что говорит литература — ILD

Оценщик ILD — это в точности plug-in по ячейкам: в каждой ячейке предсказывается мажоритарный класс, и `[FETCH: https://arxiv.org/pdf/2107.11609 · 2026-08-19]` определяет «идеальную ячейку» как содержащую наблюдения только одного класса:

> «Sometimes a bucket may contain only observations that are all in class 0 or 1. Such a bucket is called in this paper perfect bucket» `[FETCH: https://arxiv.org/pdf/2107.11609 · 2026-08-19]`

> «It is easy to see that we can create a prediction vector that will predict all cases perfectly» — про идеальный набор данных `[FETCH: https://arxiv.org/pdf/2107.11609 · 2026-08-19]`

и прямо называет предельный случай:

> «The ILD algorithm would not give any useful information on a dataset with just one observation in each bucket (since it would be a perfect dataset).» `[FETCH: https://arxiv.org/pdf/2107.11609 · 2026-08-19]`

То есть при `m = 1` их оценка неустранимой ошибки тождественно нулевая. Это и есть механизм «кажущейся детерминированности», названный авторами как определение, а не как смещение.

**Готовый диагностик населённости у них уже есть, и это надо забрать.** Perfection index

```
I_P = (1/M)·Σ_i | m₁[i] − m₀[i] |
```

с доказанным свойством `I_P = max a − min a` по всем векторам предсказаний `[FETCH: https://arxiv.org/pdf/2107.11609 · 2026-08-19]`. Отсюда элементарно `[ВЫВОД]`: `min a = (1/M)·Σ min(m₀,m₁)` — это ровно plug-in оценка байесовской ошибки, значит

```
Ê_байес = (1 − I_P)/2
```

Perfection index — аффинная перепараметризация plug-in оценки, и `I_P → 1` означает `Ê_байес → 0`, то есть вырождение. Авторы дают ему ровно то толкование, которое нужно нам как условию на данные:

> «if IP is small then the ILD algorithm will give very useful information ... The more the value of IP gets close to one, the more the analysis, as it is formulated here, is less helpful.» `[FETCH: https://arxiv.org/pdf/2107.11609 · 2026-08-19]`

Их собственная нерешённая проблема — та же самая, с другой стороны:

> «The interesting question is how to determine the maximum accuracy or the best AUC only in cases in which no overfitting is occurring. This is a nontrivial problem that is currently under investigation by the authors.» `[FETCH: https://arxiv.org/pdf/2107.11609 · 2026-08-19]`

и оговорка, наследуемая нами:

> «there is a big assumption made, namely, that a feature bucket with a few observations contains the same information as one with one thousand observations in it» `[FETCH: https://arxiv.org/pdf/2107.11609 · 2026-08-19]`

## 2.4 Что говорит литература — Table Lookup, и здесь инверсия

`[REF: Fudenberg, Kleinberg, Liang & Mullainathan 2022]`, препринт прочитан `[FETCH: https://arxiv.org/pdf/1910.07022 · 2026-08-19]`.

Их оценщик — **кросс-валидированный**, не внутривыборочный:

> «Then define the cross-validated Table Lookup error as in (3) and (4). This measure, which we will denote CV_TL, is a consistent estimator for the irreducible error E_P(f*_P).» `[FETCH: https://arxiv.org/pdf/1910.07022 · 2026-08-19]`

Про разреженность они говорят прямо и от неё **уходят**, а не решают её:

> «With an ideal (i.e. infinite) data set, Table Lookup minimizes the expected out-of-sample error, but Table Lookup can be quite imperfect when data is sparse.» `[FETCH: https://arxiv.org/pdf/1910.07022 · 2026-08-19]`

> «We work exclusively with data sets where the quantity of data is large enough that the most predictive model is approximately the most complex one, i.e. Table Lookup» `[FETCH: https://arxiv.org/pdf/1910.07022 · 2026-08-19]`

**И они же формулируют направление, которое нас разворачивает.** Про алгоритмы, применяемые как бенчмарк:

> «These algorithms are themselves potentially incomplete relative to the best achievable level, and thus provide a lower bound for the best achievable level, where the degree to which they are incomplete is a priori unknown.» `[FETCH: https://arxiv.org/pdf/1910.07022 · 2026-08-19]`

Риск любого реального правила не меньше байесовского. Значит вневыборочная ошибка `CV_TL` в конечной выборке **завышает** неустранимую ошибку: `E[CV_TL] ≥ R*`. А plug-in её **занижает**: `E[plug-in] ≤ R*`. Два оценщика зажимают истину с разных сторон `[ВЫВОД]`:

```
E[plug-in]  ≤  R*  ≤  E[CV_TL]
```

**Инверсия, ради которой написан этот файл.** Для вердикта «не разворачивать» нужна сторона, **занижающая** долю объекта. Её даёт внутривыборочный plug-in — тот, который в методической литературе считается наивным и подлежащим замене на кросс-валидацию. Кросс-валидированный `CV_TL`, записанный в гейт как предписанный оценщик, направлен в **противоположную** сторону и вердикта не несёт.

Это не значит, что `CV_TL` бесполезен: он даёт вторую сторону зажима и должен сообщаться рядом, иначе работа выглядит как выбор наивного оценщика ради удобного ответа. Но несущая сторона — plug-in.

# 3. ОГРУБЛЕНИЕ: НАПРАВЛЕНИЕ — ТЕОРЕМА, ВЕЛИЧИНА — НЕТ (задача 3b)

Направление: `[REF: Catt 2026]`, Corollary 5, «Forecastability under information-set compression», в абстракте — «compression of the information set can only reduce forecastability» `[FETCH: https://arxiv.org/html/2603.27074v1 · 2026-08-19]`. Это data processing inequality: огрубление не может увеличить достижимую предсказуемость, то есть не может уменьшить долю объекта.

Величина: **не ограничена**, и это следует из самой теоремы. DPI даёт знак и не даёт модуля; зазор `I(Y; X_тонкий) − I(Y; X_грубый)` сверху ограничен только тривиально — всей информацией, содержащейся в тонком наборе. Никакая грубая оценка не даёт основания утверждать, что тонкий набор добавил бы мало.

Литература, связывающая потерю информации при квантовании с ростом ошибки классификации, существует, но помогает не в ту сторону. Ближайшее найденное — `[REF: Silva et al. 2021]`, «Studying the Interplay between Information Loss and Operation Loss in Representations for Classification», arXiv 2112.15238. **Прочитан только абстракт через arXiv API**, полный текст не открывался, поэтому нагрузки в выводе не несёт `[FETCH: http://export.arxiv.org/api/query?id_list=2112.15238 · 2026-08-19, только абстракт]`. Из абстракта: их первый результат — «a lower bound on a weak form of information loss as a function of its respective operation loss», а основной — импликация асимптотическая: «vanishing information loss ... implies a vanishing MPE loss». Направление обратное нужному (ограничивается потеря информации через потерю в ошибке, а не наоборот), и результат асимптотический, а не конечновыборочный.

**Вывод по 3b.** Модуль огрубления не ограничен ни у Catt, ни в найденной смежной литературе. И он не нужен — при условии, что вердикт квантифицирован по объявленному набору признаков. Если квантор снять, никакая оценка модуля его не заменит.

# 4. ЕСТЬ ЛИ РЕЖИМ С ИЗВЕСТНЫМ КОНСЕРВАТИВНЫМ НАПРАВЛЕНИЕМ (задача 3c)

**Есть.** Условия ниже проверяются на данных до расчёта разложения.

**C1. Набор признаков и степень огрубления объявлены до просмотра результата.** Снимает единственное враждебное смещение (отбор степени огрубления). Совпадает с G1 и ничего сверх него не требует.

**C2. Вердикт квантифицирован по объявленному набору.** Формулировка «внутри объявленного набора признаков S достижимый выигрыш над решением без модели не превышает δ», без переноса на более богатые наборы. Corollary 5 запрещает перенос вверх, и запрет этот не количественный, а логический.

**C3. Несущая оценка — внутривыборочный plug-in, а не кросс-валидированная.** По разделу 2.4. `CV_TL` сообщается рядом как вторая сторона зажима, но вердикт на ней не строится.

**C4. Ячейки с `m = 1` входят с нулевым вкладом в неустранимую ошибку.** Это не упущение, а конструкция: нулевой вклад — минимально возможный, поэтому направление верно **по построению**, а не в среднем. Именно этот пункт превращает «смещение в среднем в нужную сторону» в настоящую одностороннюю границу.

**C5. Сообщается односторонний нижний доверительный предел на `B`, а не точка.** Пункт (iv) условия G8. Вогнутость даёт знак смещения, но не покрывает выборочный шум.

**C6. Диагностик вырождения объявлен и сообщён.** Годится `I_P` из ILD либо доля выборочной массы в ячейках с `m ≥ 2`. Пороги объявляются до расчёта. Смысл — не «оценка невалидна», а «граница вырождена и вердикт не выносится».

## Чего эти условия НЕ дают, и это надо сказать прямо

Направление гарантировано; **острота — нет.** По мере разрежения ячеек `B_низ → 0`, граница на выигрыш стремится к `½·√(π(1−π))/(1−p_t)`, и вердикт «не разворачивать» перестаёт выноситься при любом истинном `B`. То есть отрицательный исход у этой конструкции ровно один и он безобидный: **молчание, а не ошибка.**

Отсюда — заранее объявляемый исход, который надо внести в протокол: если на реальных данных нижний предел на `B` не поднимается до уровня, при котором правая часть опускается ниже объявленного `δ`, то результатом работы является не «система не окупается», а «на публичных данных при этом наборе признаков вердикт не выносится». Это законный отрицательный результат, и он отличается от того отрицательного результата, который проект объявлял раньше.

1. **G8 выполним.** Конструкция C1–C6 удовлетворяет всем четырём требованиям: сторона объявлена (снизу), совпадает с требуемой (раздел 1.5), знак установлен теоремой (раздел 2.1), предел односторонний (C5).
2. **Предписанный гейтом оценщик заменён.** Строка «Оценщик при пройденных G1–G3: Table Lookup ... плюс completeness как нормировка» относится к `CV_TL` и направлена не в ту сторону. Правится в `01-IDENTIFIABILITY-GATE.md`.
3. **Определение доли объекта фиксируется в квадратичной метрике,** не через байесовскую ошибку классификации. Основание — **не** разница в скорости смещения (этот довод снят 2026-08-19, см. раздел 2.2), а несовместимость байесовской ошибки классификации с алгеброй порога: она отвечает порогу `1/2`, а при редком исходе вырождается в `π`.
4. **Формулировка вклада в `00-THESIS.md` уточняется:** «область параметров, в которой вердикт переворачивается» перестаёт быть обещанием и получает выражение (раздел 1.4).
5. **G2 меняет смысл.** Населённость ячеек перестаёт быть условием *несмещённости* — направление верно и при `m = 1`. Она остаётся условием **неврожденности границы**. Это ослабление требования, а не ужесточение.
